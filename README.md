# Desarrollo de aplicaciones Web server side Rendering
Proyecto de la materia de DWssr

# Competencias a desarrollar
El participante identifica los frameworks mas
utilizados en la industria para el desarrollo de
aplicaciones web de pila completa y emplea uno de
ellos para desarrollar aplicaciones web siguiendo las
mejores practicas de desarrollo.

# Convencion de Iconos para Commits
| Icono | Tipo de Commit | Descripción |
| :---: | :--- | :--- |
| ✨ | **`feat`** — Nueva funcionalidad | Adición de una nueva característica, componente o pantalla a la aplicación web. |
| 🐛 | **`fix`** — Corrección de errores | Solución de bugs, fallos de lógica o problemas imprevistos en el código. |
| 🎨 | **`style`** — Estilos y diseño | Modificaciones en hojas de estilo (CSS, SCSS, Tailwind) o formato visual que no alteran la lógica de programación. |
| 📝 | **`docs`** — Documentación | Actualización o creación de archivos de documentación, como el README, manuales de usuario o guías de instalación. |
| ♻️ | **`refactor`** — Refactorización | Reestructuración del código existente para mejorar su legibilidad y mantenimiento sin cambiar su comportamiento externo. |
| ⚡ | **`perf`** — Rendimiento | Optimizaciones orientadas a mejorar la velocidad de carga, la eficiencia de scripts o el consumo de recursos del sitio web. |
| 🧪 | **`test`** — Pruebas | Adición, eliminación o modificación de pruebas unitarias, de integración o end-to-end. |
| 🔧 | **`chore`** — Mantenimiento y configuración | Cambios en herramientas de construcción, gestión de dependencias (`package.json`), librerías o archivos de configuración del entorno de desarrollo. |
